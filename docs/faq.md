# FAQ

**Which Windows versions work?** 64-bit Windows 10 (version 2004 or later) and Windows 11.

**Do I need an account?** Hiding windows needs nothing. The AI needs a provider key or a license that includes AI.

**Does it work offline?** Hiding windows and audio transcription work offline. AI answers need the internet.

**How much does the AI cost?** Usually one or two US cents per question. Set a daily cap in Settings → Providers.

**Is my screen or voice uploaded?** No. Only text you choose to send, and only when you press send. See [Privacy](privacy.md).

**My antivirus flags it.** Apps that work with other windows are sometimes flagged. Report it as a false positive to the antivirus vendor.

**Which apps does it hide windows from?** Zoom, Teams, Meet, Discord, OBS, Snipping Tool, Xbox Game Bar and the Windows 11 recorder. See [Limits](limitations.md) for what it can't hide from.

**Does it work with several monitors?** Yes.

**Installer or portable?** Same features. The installer updates itself; the portable version doesn't. See [Portable](portable.md).

**How do I remove everything?** Uninstall from Windows Settings (or delete the portable folder), and choose to delete your data when asked.

**Is it open source?** No. It is licensed software; see the agreement shown during installation.

**How do I report a problem?** [Open an issue](https://github.com/NullCapture/releases/issues).
