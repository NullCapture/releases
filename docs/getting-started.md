# Getting started

## Install

1. Download the `.msi` from the [Releases page](https://github.com/NullCapture/releases/releases/latest).
2. Run it. No administrator rights are needed.
3. If Windows SmartScreen warns about an unrecognised publisher, choose **More info**, then **Run anyway**, only if you downloaded the file from this page.
4. Open **Privacy AI Assistant** from the Start menu.

Prefer not to install? See the [portable version](portable.md).

## First launch

A short consent screen asks what the app may use. Screen text and audio are **separate choices**. Audio is off unless you turn it on.

A small floating bar then appears near the top of your main screen. Click it to open the assistant.

## Hide a window

1. Open **Settings → Windows**.
2. Tick the windows to keep private, or use the crosshair button and click a window.
3. Or click a window and press `Ctrl+Shift+P`.

The window looks normal to you. Screen shares and recordings show it blank. More in [Hiding windows](window-protection.md).

## Use the AI assistant

1. Open **Settings → Providers**, add your AI provider's key (or activate a license that includes AI), and set a daily spending cap.
2. Click the floating bar, type a question, and press `Ctrl+Enter`.
3. Use the **screen** toggle to choose whether your on-screen text is included.

More in [Using the AI assistant](ai-assistant.md).
