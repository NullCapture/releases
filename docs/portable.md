# Portable version

Runs without installing.

1. Download `PrivacyAI-portable-v<version>.zip` from the [Releases page](https://github.com/NullCapture/releases/releases/latest).
2. Extract it to any folder, such as a USB drive.
3. Run `PrivacyAI.exe`.

Settings and data are stored in that folder. Move or delete the folder to move or remove everything. Provider keys you add are stored in Windows secure storage on that computer; remove them in **Settings → Providers**.

The portable version doesn't update itself. **Check for updates** opens the Releases page.
